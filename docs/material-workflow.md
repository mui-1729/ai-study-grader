# 元資料から学習を始めるまで

## 推奨する流れ

1. アプリの「教材を追加 → プロンプトをコピー」から指示文を取り出し、元の講義資料・教科書・ノートと一緒に、教材作成を任せるAIに渡す。全文表示・テキストのダウンロードも同じ画面から行える。指示文の原稿は `docs/create-material-prompt.md` にあり、アプリにも同じ本文を表示する。
2. AIから、教材本文・問題・模範解答・採点基準・復習先を含む `course-....json` と、作成確認レポートを受け取る。
3. レポートで読めた範囲・未確認箇所を見て、問題と解答の一部を元資料と照合する。
4. `npm run validate:package -- "C:\path\to\course.json"` で形式を確認する。この操作は教材の追加やAI接続を行わない。
5. アプリの「教材を追加」からJSONを選び、読む・解く・採点・復習を始める。

形式検証はJSONの構造・配点・参照先を確認するもので、内容の正しさや出典の実在を保証しない。問題・模範解答・部分点の妥当性も確認する。

## 元資料はアプリにも追加するべきか

学習・採点に必須なのは完成した教材パッケージである。元資料は、手元に保存して照合できればよく、毎回アプリへ重ねて入れる必要はない。

元の文章もアプリで読みたい場合は、PDF・Markdown・テキストとして別の教材に追加できる。ただし、現在は**別教材同士を自動的に関連付けず、採点時に他の教材を横断検索しない**。元PDFを別に追加しても、生成した問題の採点根拠が自動で増えるわけではない。

AI採点に使われるのは、同じパッケージ内の問題・模範解答・採点基準・指定された復習章の抜粋である。したがって、生成パッケージ内に必要な定義や条件を含め、章本文に元ファイル名・ページ等の参照先を残す。元資料が図表中心なら、図表が正しく説明へ反映されているかも確認する。

## アプリ内で作成する流れ

1. 「教材を追加」でPDF・Markdown・テキストを入れ、抽出された本文を確認する。
2. 元資料の学習画面で「この資料からAI教材を作る」を開く。
3. 開始区間と呼び出し回数を指定し、送信範囲を確認して「教材を生成」を押す。初期値は3回。1回あたり本文最大6,000文字を送る。
4. 生成された解説・確認問題・参考解答・採点基準を元資料と照合する。
5. 「確認した内容を新しい教材として登録」を押し、学習を始める。

作成にもINIAD AI-MOPの同じ利用枠を使う。quotaの確認値は現在の残量ではないため、残量を仮定して自動で作成を始めない。制限・出力不正で停止したら成功した区間を残し、自動再送しない。長い資料の続きは開始区間を変えて別の教材として作れる。アプリ終了で中断した処理も自動再開しない。

アプリ内生成は、テキストの資料を区間ごとに解説・出題する用途に向く。図表・複雑な数式・章をまたぐ総合問題は、元資料を直接読める外部AIに依頼し、対話で修正してJSONを取り込む流れが引き続き便利。PDFの図表をアプリ内生成で読み直すことはできない。生成した教材と元資料は自動横断検索で結び付けない。
