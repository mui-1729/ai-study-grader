# 教材パッケージ形式 v1

1科目をUTF-8のJSONファイルにします。完全なサンプルは `examples/sample-course.json` です。APIキー・個人情報・答案を教材JSONへ入れないでください。

| 項目                   | 内容                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| `schemaVersion`        | 数値 `1`                                                                     |
| `id`                   | 教材固有のID。英小文字・数字・`-`・`_`、最大80文字。先頭は英小文字または数字 |
| `version`              | 改訂を区別する文字列                                                         |
| `title`, `description` | 科目名と説明                                                                 |
| `gradingPolicy`        | 同義表現や別解、重複減点などの採点方針                                       |
| `chapters`             | 章の配列。各章は `id`, `title`, `content`（Markdown）                        |
| `questions`            | 問題の配列。教材本文のみなら空配列も可能                                     |

各問題は以下を持ちます。

| 項目                       | 内容                                                                    |
| -------------------------- | ----------------------------------------------------------------------- |
| `id`, `chapterId`, `title` | 問題ID、所属する章ID、問題名                                            |
| `kind`                     | 記述式は `written`、厳密一致は `exact`                                  |
| `prompt`                   | 問題文。Markdown可                                                      |
| `maxPoints`                | 満点。1〜1,000の整数                                                    |
| `modelAnswer`              | 模範解答・解説。Markdown可                                              |
| `rubric`                   | 部分点と減点の根拠。配点が分かるように記載                              |
| `criteria`                 | `{id, description, maxPoints}` の配列。配点合計は問題の満点と一致させる |
| `acceptedAnswers`          | 厳密一致で許容する正解の文字列配列。記述式では `[]`                     |
| `reviewChapterIds`         | 復習先の章IDの配列                                                      |
| `section`                  | 通常の確認問題は `practice`、模試の問題は `mock`                        |

章・問題・観点のIDは、それぞれの範囲で重複させません。所属・復習先の章は実在しなければ登録できません。教材本文・問題文・解答などは1フィールド100,000文字以内、最大200章・2,000問です。

`exact` の採点はUnicode NFKCによる全角・半角等の正規化と前後の空白除去後の完全一致です。大文字小文字、文中の空白、数式の同値変形を自動では判定しません。必要な別表記を `acceptedAnswers` に列挙するか、記述式にします。選択問題も選択肢を問題文へ書き、選択肢記号を厳密一致で採点できます。

## まとめやテストをチャットで作るとき

資料と一緒に「このアプリのサンプルJSONと同じ形式で、教材・問題・模範解答・部分点の採点基準・復習先を含む教材パッケージを作って」と依頼し、この形式かサンプルを添えます。生成した問題・解答は内容を確認してから取り込みます。本文をそのまま命令として実行する機能はありません。

元の講義資料や著作物の公開可否は、アプリの公開可否とは別です。教材JSONは `data/` に保存し、コードのリポジトリには含めません。
